RGX | Framework
One dependency. Everything your addon suite needs.
Overview
RGX-Framework is a modern, shared WoW addon framework for Retail and supported Classic clients. It provides events, timers, hooks, slash commands, saved-variable helpers, fonts, colors, textures, dropdowns, UI controls, minimap buttons, options panels, aura helpers, combat callbacks, sound, and more without LibStub embedding.

2.7.2 Event Lifecycle Hotfix
Deferred WoW frame-event registrations now flush when outer framework event or timer dispatch returns to a safe state. Consumer addons that register feature events during login no longer end up with callbacks present in Lua but missing native WoW event registration. Unit-event cleanup is symmetric and combat-deferred registrations remain queued until safe.
Quick Start
## RequiredDeps: RGX-Framework
## SavedVariables: MyAddonDB

RGXAddon "MyAddon" {
  slash = "myaddon",
  minimap = true,
  db = { enabled = true },
}
Distribution
RGX-Framework publishes one runtime-only addon product. The GitHub release contains RGX-Framework-v2.7.2.zip plus release.json automation metadata. Source documentation, schemas, tests, and tooling are not included in player installs.
