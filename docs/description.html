RGX | Framework
One dependency. Everything your addon suite needs.
Overview
RGX-Framework is a modern, shared WoW addon framework for Retail, Classic Era, TBC, Wrath/Titan, Cataclysm, and Mists. One dependency provides events, timers, hooks, slash commands, saved-variable helpers, fonts, colors, textures, dropdowns, UI controls, minimap buttons, options panels, aura helpers, combat callbacks, sound, and more without LibStub embedding. It is not a player-facing addon: it loads silently and exposes an API.

What It Provides
• Lifecycle — OnReady, OnLogin, module readiness tracking
• Events & Messages — Blizzard event registration, internal message bus, module-local emitters
• Timers — After, Every, CancelTimer on a native OnUpdate driver
• Hooks — safe post-hooks via hooksecurefunc
• Slash Commands — RegisterSlashCommand, no raw SLASH_ boilerplate
• Combat Queue — QueueForCombat, SafeShow, SafeHide, SafeSetPoint
• Fonts — 40 bundled + 4 WoW defaults, style objects, grouped dropdowns
• Colors — named palette, class/quality/power colors, color math, picker integration
• Textures — statusbar registry, LibSharedMedia import
• Dropdowns & UI — nested menus, sliders, toggles, color pickers, tabbed options panels with WoW Settings integration
• Minimap — circular-drag buttons with persistent angle
• Design — static brand palette and visual building blocks
• DataBroker — LibDataBroker-compatible proxy data sources
• Game Modules — Combat, Reputation, Achievement, LevelUp, Collectibles, Loot, Quest, Honor, Delves, Housing, TradingPost, Prey, PetBattles, Sound, SharedMedia
Quick Start
## RequiredDeps: RGX-Framework
## SavedVariables: MyAddonDB

RGXAddon "MyAddon" {
  slash = "myaddon",
  minimap = true,
  db = { enabled = true },
}
That is a complete addon: profile-aware saved settings, a tabbed options panel with db-bound controls, a slash command, a minimap button, and branded chat output. Individual systems are also available à la carte through RGX:RegisterEvent, RGX:After, RGX:GetFonts(), RGX:GetColors(), RGX:CreateMinimapButton, and friends.
Font Coverage
44 registered fonts: 40 bundled (30 selectable across Sans/UI, Serif, Monospace, Display, Pixel, and Fantasy families) plus 4 WoW defaults (Friz Quadrata, Arial Narrow, Morpheus, Skurri). Font pack addons can extend the registry at runtime with Fonts:RegisterFontPack(). Attribution for all bundled fonts lives in Font Sources & Licenses.

Distribution
RGX-Framework publishes one runtime-only addon product. The GitHub release contains RGX-Framework-v2.7.8.zip plus release.json automation metadata. Source documentation, schemas, tests, and tooling are not included in player installs. Framework code is licensed under the MIT License; bundled fonts retain their own open licenses.
