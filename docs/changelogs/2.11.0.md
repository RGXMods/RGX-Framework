# RGX-Framework v2.11.0

Package: `RGX-Framework-v2.11.0.zip`, 106 runtime files, plus `release.json`.

- New `RGXTriggers` module: a trigger state store for the trigger evaluation
  engine (rgx-mod substrate). Trigger authors mutate clone-keyed state and the
  engine diffs every field write — `state.changed` only flips when a value
  actually changed or the clone is new, so consumers react to real changes
  and identical writes cost nothing.
- Stale clones cannot survive: `Sweep(keepIds)` removes every clone the author
  did not keep alive in one coalesced notification; `Remove` and `Clear`
  cover the single-clone and all-clone cases.
- Guaranteed progress shapes: `UpdateProgress` applies the timed form
  (`duration`/`expirationTime`/`autoHide`) or the static form
  (`value`/`total`/`inverse`) with `progressType` on every state, and
  switching forms clears the other form's fields in the same diff, giving
  conditions and displays one stable shape to read.
- Change notifications (`Triggers:OnChanged(id, fn)`) are failure-isolated:
  one handler error cannot break dispatch or other handlers.
- Design provenance: AddonLearner curated pass 5 (weakauras @ 37c3950c) —
  the clone-keyed, engine-diffed state contract.
- Current public APIs and client Interfaces are unchanged. No SavedVariables
  change is required.
