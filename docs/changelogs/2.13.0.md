# RGX-Framework v2.13.0

Package: `RGX-Framework-v2.13.0.zip`, 106 runtime files, plus `release.json`.

- `RGXMinimap:Create` now also registers the button in Blizzard's Addons menu on the minimap (`AddonCompartmentFrame`). The entry uses the button icon, shows the same tooltip, and runs the same left-click and right-click handlers. Addons that already create a framework minimap button gain the entry with no change.
- The entry stays available when the round minimap button is hidden or collected by another addon.
- `compartment = false` skips the entry. `compartmentText` sets the menu label (default: `title`, then `tooltip.title`, then the button name).
- Clients without `AddonCompartmentFrame` skip registration silently.
- Added compartment coverage to `tools/ci/secure-minimap-runtime-test.lua`.
