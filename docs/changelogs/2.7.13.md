# RGX-Framework v2.7.13

First stable release of the shared UI batch (previously in beta as
v2.7.13-beta.1 through v2.7.13-beta.2).

- Profiles panel: preset pagination in the card header, confirmed per-row
  Delete in the profile dropdown, create-from-current deep-copy support, and
  a simplified reference-matched action stack.
- Options panels: `panel:Close()` / `panel:Toggle()` through the framework's
  safe-hide boundary, aware of the Settings-embedded host.
- Switch control factory: `UI:CreateSwitch` for module-page toggles used by
  consumers' card and page headers.
- Titled configuration dialogs and gear buttons (`UI:CreateConfigDialog`,
  `UI:CreateConfigButton`) as shared chrome.
- Slider purpose labels stay visible; numeric values can be hover-only
  (`valueDisplay = "hover"|"none"`), with persisted visual restore.
- Dropdown modern context-menu path with restored selection labels and
  reclaimed inline-action rows on menu recycling; legacy path rejects
  unsupported capabilities cleanly rather than misrendering.
- Layout: card auto-height and column-sharing fixes; reset controls share one
  alignment owner.
- Regression coverage across profiles, layout, controls, dropdowns, options
  toggling, database reset/poisoning recovery, and six-flavor packaging.

Package: `RGX-Framework-v2.7.13.zip`, 109 runtime files, plus `release.json`.
