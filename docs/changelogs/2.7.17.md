# RGX-Framework v2.7.17 - 2026-10-13

- Add opt-in secure minimap item actions through `secure = true` and
  `btn:SetItemAction(itemID/nil)`.
- Preserve the secure template's OnClick; run preparation callbacks once on
  release, after its action. The next hardware left-click uses the prepared item.
- Guard secure creation, attribute changes, placement, visibility and dragging
  during combat. Right-click cannot execute the configured item action.
- Keep ordinary minimap behavior unchanged. Retail same-icon use was accepted
  by the operator; secure opt-in on other flavors is not independently validated.

Package: `RGX-Framework-v2.7.17.zip`, 111 runtime files, plus `release.json`.
Source-only tests, documentation, reference data and tooling are not packaged.
