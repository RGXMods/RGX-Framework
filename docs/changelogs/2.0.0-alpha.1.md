## v2.0.0-alpha.1

### RGX.Addon() — One Call Addon Factory
- `RGX.Addon("Name", { db, slash, minimap, brand, welcome, options, onInit })`
- Auto-creates database (NewDatabase), slash commands, minimap button
- Declarative options panel: `{ toggle = "key" }`, `{ slider = "key", min, max }`, `{ dropdown = "key", items }`, `{ button = "Label", action = fn }`, `{ section = "Title" }`
- All controls auto-bound to `addon.db` via proxy `__newindex`
- Brand color: `brand = "05dffa"` → `[MYADDON]` chat prefix

### Proxy Fix
- `__index` no longer falls back to `_defaults` at read time
- Defaults deep-merged at profile creation AND every switch (correct for nested tables)
- New settings in future versions picked up on next profile switch

### Declarative Options Engine
- `{ toggle = "key" }` → `UI:CreateToggle(frame, { storage = addon.db, key = "key" })`
- `{ slider = "key", min, max }` → `UI:CreateSlider(frame, { storage = addon.db })`
- `{ dropdown = "key", items }` → `Drops:CreateNestedDropdown(frame, ...)`
- `{ button = "Label", action = fn }` → `UI:CreateButton(frame, ...)`
- `{ section = "Title" }` → `UI:CreateSection(frame, "Title")`
- `{ label = "text" }` → `UI:CreateLabel(frame, ...)`

### Fixes
- Timer-slow threshold: 50ms → 250ms (SharedMedia:QueueScan ~207ms is normal I/O)
- `safeRegisterFrameEvent` uses `pcall(function() ... end)` wrapper for combat safety
