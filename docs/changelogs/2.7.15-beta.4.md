# RGX-Framework v2.7.15-beta.4

Beta candidate; stable remains v2.7.14. This source snapshot is not evidence of
publication or new in-game compatibility/safety acceptance.

## Changes

- Move declarative tab composition from core into a private UI-options
  compositor. Core keeps declaration resolution, storage and lifecycle; tabs
  are still built lazily through the existing scroll/column/flow/control
  factories with unchanged forms and callbacks.
- Enforce one defining file per `RGX.API` name: `core/compat.lua` owns the
  normalized implementations, `core/compat_api.lua` only adds names it does
  not define, and `tools/ci/api-ownership-check.mjs` guards the XML load list
  alongside the existing compat-loader check.

Package: `RGX-Framework-v2.7.15-beta.4.zip`, 109 runtime files, plus
`release.json` automation metadata. Tooling and reference caches stay excluded.

## Tester Checks Still Required

- Reopen, resize and switch tabs/profiles in one- and two-column options panels;
  verify geometry, scrolling and persisted visual state on affected clients.
- Confirm font restoration and button behavior in real consumer panels.
- Verify combat/protected execution where affected; headless checks do not
  establish in-game taint or geometry correctness.
