# RGX-Framework 2.7.8 (unreleased candidate based on v2.7.7)

- RGXDesign restyles the framework default look after the BugTabs
  aesthetic: dark navy panels (`#161820` family) with a cyan
  `#00e6ff` primary accent and a gold secondary accent.
- Panels are now rounded by default: `Design:CreateFrame` nine-slices
  the new `media/panel_rounded.tga` texture (12px corners) into a
  1px border ring plus tinted fill. Pass `opts.square = true` for the
  legacy flat backdrop, or `opts.radius` to change the corner size.
  `Design:ApplyBackdrop` keeps the legacy square behavior.
- New palette keys: `panelAlt`, `label`, and retuned `surface`,
  `background`, `text`, `subtext`, `border`, `hover`, `track`,
  `warning`, `error`.
- Section headers and button labels use the Inter font shipped in
  `media/fonts`, with the client's standard font substituted for
  koKR/zhCN/zhTW/ruRU locales that Inter does not cover. Text gains a
  soft 1px shadow.
- Published asset name: `RGX-Framework-v2.7.8.zip`; the addon archive
  contains 102 runtime files.
