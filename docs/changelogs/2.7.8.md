# RGX-Framework 2.7.8

Released 2026-09-25.

- RGXDesign restyles the framework default look after the BugTabs
  aesthetic: dark navy panels (`#161820` family) with a cyan
  `#00e6ff` primary accent and a gold secondary accent.
- Panels are now rounded by default: `Design:CreateFrame` nine-slices
  the new `media/panel_rounded.tga` texture (12px corners) into a
  1px border ring plus tinted fill. Pass `opts.square = true` for the
  legacy flat backdrop, or `opts.radius` to change the corner size.
  `Design:ApplyBackdrop` keeps the legacy square behavior.
- New palette keys: `panelAlt`, `label`, and retuned `surface`,
  `background`, `text`, `subtext`, `border`, `hover`, `track`,
  `warning`, `error`.
- Section headers and button labels use the Inter font shipped in
  `media/fonts`, with the client's standard font substituted for
  koKR/zhCN/zhTW/ruRU locales that Inter does not cover. Text gains a
  soft 1px shadow.
- Minimap `Button:GetAngle` now reads the durable
  `RGXFrameworkDB.RGXMinimapPositions` store before callback-backed and
  flat-storage sources, so dragged positions survive SavedVariables
  loss for every consumer path (not just storage-backed buttons).
- New `Design:WithTheme(theme, fn)` scoped-theme helper: applies a
  theme override while `fn` runs, then restores the previous colors, so
  an addon can paint its own brand panel without permanently mutating
  shared RGXDesign defaults.
- Options panel tab buttons now honor the panel's own `theme` at
  runtime: `UI:CreateOptionsPanel` stores `panel.theme` and the tab
  hover/active states resolve the brand `primary` from it (falling
  back to the shared default). The build-time `Design:SetTheme` is
  restored after construction so one addon's brand cannot leak into
  panels built later.
- Published asset name: `RGX-Framework-v2.7.8.zip`; the addon archive
  contains 102 runtime files.
