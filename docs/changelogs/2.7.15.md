# RGX-Framework v2.7.15

Non-beta release candidate; the published stable release remains v2.7.14.
Installation for testing does not establish publication or in-game acceptance.

## Changes

- Update Retail compatibility to Interface `120105` for client 12.1.5.70340.
- Promote the current 2.7.15 beta source to a non-beta candidate version.
- Preserve all Classic and Forever Interface values, dependency metadata,
  existing distribution IDs, and the shared runtime load order.
- Correct the SharedMedia font test's source path after the library move.

The existing changes from [v2.7.15-beta.4](2.7.15-beta.4.md) are retained.
Package: `RGX-Framework-v2.7.15.zip`, 111 runtime files, plus `release.json`.
Tooling and reference caches remain excluded from the player archive.
