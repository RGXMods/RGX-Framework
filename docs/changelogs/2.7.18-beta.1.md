# RGX-Framework v2.7.18-beta.1 - 2026-10-14

Beta database hotfix; latest stable release remains `v2.7.17`.

## Fixed

- `Adopt()` no longer adopts its own database handle or live settings view as
  raw SavedVariables. It restores the original owner without losing explicit
  false/zero values or breaking captured views and profile switching.
- Recovery from a metatable-poisoned profile store now constructs a writable
  active profile with independent defaults. Settings writes no longer disappear.
- Added Lua 5.1 regression coverage: alias adoption previously raised
  `C stack overflow`; recovered-store writes previously failed persistence.

No new API, declarative keys, client API calls, or addon settings reset.
The same core database implementation serves all supported flavors.

## Validation boundary

Automated Lua 5.1 scenarios are not in-game evidence. Before stable promotion,
verify Retail 12.1.5 nameplate adds/removals, `/sqp help`, `/sqp status`,
`/sqp test`, options changes, explicit false/zero values across `/reload`,
and switching profiles. Do not delete SavedVariables to test this fix.

Package: `RGX-Framework-v2.7.18-beta.1.zip`, 111 runtime files, plus `release.json`.
