# RGX-Framework 2.6.0

## Multi-Flavor Runtime

- Added verified TOCs for Retail, Classic Era, TBC Classic, Wrath/Titan,
  Cataclysm, and Mists Classic.
- Added capability-aware module initialization so unsupported expansion
  features do not register or appear available.
- Normalized aura, quest-log, and reputation access across modern and legacy
  client APIs.
- Added shared-frame fallback behavior for templates not present everywhere.
- Added deterministic six-flavor Lua 5.1, TOC, and package-inventory checks.

## Distribution

- The player package remains runtime-only.
- `RGX-Developer` is now a data-only contract SDK with no MCP server,
  `.mcp.json`, Node entrypoint, or executable tooling.
- The source-tree MCP remains temporarily for contract-conformance CI. Public
  MCP/API/editor distribution belongs to RGX Studio after production gate #30.
