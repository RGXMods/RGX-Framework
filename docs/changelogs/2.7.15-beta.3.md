# RGX-Framework v2.7.15-beta.3

Beta candidate; stable remains v2.7.14. This source snapshot is not evidence of
publication or new in-game compatibility/safety acceptance.

## Changes

- Add declarative `options.columns = 1|2|3` using existing column/flow primitives.
  This does not implement declarative cards or multi-page tabs.
- Reject malformed one-line controls before addon/event/slash registration;
  preserve signed slider bounds, positive steps and addon-owned method buttons.
- Delegate string fonts to the existing bound selector. Profile changes
  invalidate lazy tabs before refreshing visible controls.
- Preserve imperative table-control additions/replacements during `onInit`.
- Route MCP validation/preflight through the shared engine, deriving future-key
  reports from schema annotations; share validation vectors with direct callers.
- Refresh the Ace3 comparison, foundation, modularity, authoring and distribution
  docs. Align checks with the moved service-description sources and current
  `https://realmgx.com` community link.

Package: `RGX-Framework-v2.7.15-beta.3.zip`, 109 runtime files, plus
`release.json` automation metadata. Tooling and reference caches stay excluded.

## Tester Checks Still Required

- Reopen, resize and switch tabs/profiles in one- and two-column options panels;
  verify geometry, scrolling and persisted visual state on affected clients.
- Confirm font restoration and button behavior in real consumer panels.
- Verify combat/protected execution where affected; headless checks do not
  establish in-game taint or geometry correctness.
