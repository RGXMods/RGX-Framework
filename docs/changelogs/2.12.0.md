# RGX-Framework v2.12.0

Package: `RGX-Framework-v2.12.0.zip`, 106 runtime files, plus `release.json`.

- Added `onPreview` to `CreateNestedDropdown`. Each leaf with a value gets a Play/Stop button that calls `onPreview(value, item, holder)`. Use `isPreviewing(value, item, holder)` to show Stop while a value plays, `previewLabel` and `previewStopLabel` to change the text, and `item.preview = false` to skip a row.
- Menus with `onPreview` use the UIDropDownMenu path, because MenuUtil rows expose no list frame that `ForceWidth` can size. The framework reserves row width for the Play button, so consumers do not list its key in `autoWidth.opts`.
- Added `holder:RefreshPreviews()` to re-read Play/Stop labels after playback ends.
- Play buttons are cleared whenever any dropdown builds a menu level, because menu rows are shared between open dropdowns.
- Documented the Play button API in `docs/DROPDOWNS.md`.
