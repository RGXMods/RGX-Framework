# RGX-Framework v2.8.1 - 2026-10-19

- Repaired the WoW reference cache: sync handles empty/nested `.reference`
  directories, API dumps and shipped UI source are complete and current, and
  the freshness doctor records inventory counts and surfaces upstream dump lag.
- Restored `modules/` as the game-domain module directory. Library modules
  remain under `libraries/`; the public runtime API and category semantics are
  unchanged.
- Completed the consumer-neutrality sweep and stopped CI from encoding consumer
  addon identities. The public GitHub mirror is paused behind an explicit
  sanitization gate.
- Framework diagnostics now expose `/rgxframework` and `/rgxf` under the
  `RGXFRAMEWORK` token. `/rgx` remains a legacy alias, and another addon's
  `RGX` token is preserved.
- Library-owned media moved under `libraries/fonts/media/`,
  `libraries/colors/`, and `libraries/design/`; `media/` now holds framework
  branding only. Saved legacy `media/fonts/...` paths continue to resolve by
  basename.
- The package now ships `AGENT-DIRECTIVE.md`, which tells user agents to obtain
  the matching docs and upstream WoW API references themselves.
- Current public APIs and client Interfaces are unchanged. No SavedVariables
  deletion is required.

Update RGX-Framework, then fully restart WoW.
