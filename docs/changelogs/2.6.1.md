# RGX-Framework 2.6.1

## Distribution Correction

- Removed the mistaken secondary product and artifact concept entirely.
- RGX-Framework publishes only the WoW addon framework package.
- Schemas, docs, reference utilities, and the temporary MCP conformance fixture
  remain source-only.
- Future public API, MCP, editor, and contract-bundle distribution belongs to
  RGX Studio.
- Corrected deterministic package metadata to include all six flavor TOCs and
  identify all supported clients.
- Corrected premature documentation claims for declarative `on` and `every`;
  both remain frozen future contract forms pending their runtime implementation.
