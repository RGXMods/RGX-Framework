# RGX-Framework v2.17.7

Package: `RGX-Framework-v2.17.7.zip`, 106 runtime files, plus `release.json`.

- Options panels now follow their interface style. A panel's tab content is built when the panel first opens, after the `Design:WithStyle` scope that built the panel has ended, so the content was drawn in the default style: an RGX Material Round panel opened with default-looking cards and controls. The panel now remembers the style it was created in and re-applies it for every content build.
- New `style` option on `UI:CreateOptionsPanel` (for example `style = "materialround"`) builds the whole panel in that style without changing the operator's global choice. See [UI-CONTROLS](../UI-CONTROLS.md).
