# RGX-Framework 2.7.4

Released 2026-08-23.

## Consistent chat output

- Framework `Print`, `Warn`, `Error`, and `Debug` output now share the standard
  framework icon, ` - ` spacer, and `[RGX]` tag.
- `RGX:CreateChatPrefix()` uses that branded format by default while preserving
  advanced icon, tag, color, size, and spacer overrides.

## Login-message preference

- Added `RGX:IsLoginMessagesEnabled()`,
  `RGX:SetLoginMessagesEnabled(enabled)`, and
  `RGX:LoginMessage(message, opts?)`.
- The preference persists globally as `RGXFrameworkDB.showLoginMessages` and
  defaults to enabled.
- `/rgx login on|off|status` manages the preference. Command confirmations use
  normal output, so disabling login messages still confirms the change.
- Declarative `welcome` strings obey the global preference.
- Framework initialization emits one gated, metadata-derived startup line;
  compatibility diagnostics remain debug-only.

## Verification

- Added Lua 5.1 runtime coverage for the default, persistence, disabled and
  re-enabled output, slash commands, declarative welcome routing, standard
  prefix shape, and single framework startup line.
- Syntax, schema, flavor, package, documentation, and declarative runtime
  checks remain required for release.

## Distribution

Published assets are `RGX-Framework-v2.7.4.zip` and `release.json`.
The addon archive contains 100 runtime files and all six supported flavor TOCs.
