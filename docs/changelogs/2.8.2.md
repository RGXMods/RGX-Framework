# RGX-Framework v2.8.2 - 2026-10-19

- New declarative `compat` key resolves the first callable global API path on
  the current client into `addon.compat.<name>(...)`. Bare path and ordered
  fallback-list forms cover the common expansion-drift case; the advanced
  `prefer`/`fallback` form adds an optional `normalize` function that receives
  the raw return values. Declarations with no callable path fail before the
  addon registers, so a wrong-API-for-expansion call site cannot reach runtime.
- The runtime package now ships the expanded `AGENTS.md` project entry point
  for both installed-addon agents and source-tree agents. It replaces the
  shorter `AGENT-DIRECTIVE.md`; the runtime file count is unchanged.
- Current public APIs and client Interfaces are unchanged. No SavedVariables
  deletion is required.

Update RGX-Framework, then fully restart WoW.
Package: `RGX-Framework-v2.8.2.zip`, 114 runtime files, plus `release.json`.
