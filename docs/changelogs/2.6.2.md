# RGX-Framework 2.6.2

## Documentation And Release Integrity

- Synchronized the README, canonical documentation, addon-service description
  source, release metadata, and generated Wiki with the runtime-only six-flavor
  distribution.
- Corrected Quick Start examples to declare their SavedVariables table and use
  only shipped declarative behavior.
- Clarified that the in-tree MCP is a private, source-only conformance fixture;
  future public API, MCP, editor, and contract-bundle tooling belongs to Studio.
- Corrected the restricted-aura boundary: `pcall` isolates Lua errors but does
  not prevent or undo taint. Arbitrary any-unit aura payloads remain best-effort
  until the tracked runtime hardening work is complete.
- Added CI checks for versioned public surfaces, six-flavor metadata, exact
  package inventory, complete Wiki mapping, and the real RGX-Hello opts table.
- Hardened tag publishing with a preflight package inspection, exact published
  asset validation, release metadata validation, and same-run SHA verification.
- No public runtime API semantics changed in this patch.
