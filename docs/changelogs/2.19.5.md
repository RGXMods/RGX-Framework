# RGX-Framework v2.19.5

Package: `RGX-Framework-v2.19.5.zip`, 110 runtime files, plus `release.json`.

- DataBroker notifications and native tooltip hooks keep dispatching if a consumer's callback error cannot be formatted or its diagnostic reporter fails.
- Tooltip composition continues past a bad line even if reporting that line fails. A hover builder's diagnostic failure no longer escapes its hover handler.
- Existing public APIs, callback arguments, native registration and ordinary diagnostics are unchanged.
