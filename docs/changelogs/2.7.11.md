# v2.7.11

Stable release completing the v2.7.10 distribution chain (the v2.7.10
GitHub release published, but CurseForge/Wago uploads failed on a publisher
bug) and shipping the fixes accumulated since the v2.7.10 tag.

## Distribution fix

- **CurseForge upload fixed.** The in-house publisher sent the upload
  metadata as a Blob file part; CurseForge's API requires a plain string
  form value (BigWigs `curl -F` parity) and answered
  `1001 Missing field metadata`. The metadata field is now a plain form
  value, so the release workflow completes on all channels.

## Runtime fixes and features

- **Settings canvas fill.** Panels registered with the game's Settings
  window now fill their canvas container instead of floating at fixed size
  inside Blizzard's chrome — the double frame and extra background around
  embedded options panels (reported on SimpleQuestPlates) are gone. The
  close button hides in canvas mode; floating panels keep centered sizing.
- **Taller framework header.** Options-panel header band 52 -> 64px,
  suite icon 28 -> 42px, identity rows redistributed; panel default
  height 620 -> 632.
- **Proper-alpha suite icons.** The round (minimap) and square (header)
  brand icons shipped in v2.7.10 were fully opaque (the source art has no
  alpha channel), so the round icon rendered as a dark square on the
  minimap. Both are regenerated with edge-connected background keyed to
  transparent: round clears its corners, square keeps its full-bleed
  badge, and interior art is never punched through.
- **Consumer-agnostic runtime.** The framework is a framework: all
  consumer-addon name references were removed from runtime comments, the
  database fixture, and the contract schema, the consumer-coupled
  lifecycle harness moved to the SimpleQuestPlates repository, and the
  runtime boundary check now fails CI on any consumer addon name appearing
  in `core/` or `modules/` Lua — code or comments.
- **Classic Era on the base TOC.** `RGX-Framework.toc` now declares
  `120100, 16001, 11509`, so Era clients load the base addon without the
  dedicated flavor TOC.

## Compatibility

- One framework, one instance, one dependency: `RequiredDeps: RGX-Framework`.
- Retail `120100` + WoW Forever beta `16001` + Classic Era `11509` in the
  base TOC; TBC `20506`, Wrath/Titan `38002`, Cataclysm `40402`, Mists
  `50504` in their flavor TOCs. All six ship together.
- Player archive: `RGX-Framework-v2.7.11.zip` — 108 runtime files (TOCs,
  XML, core, modules, media, license). No tooling, docs, schemas, or
  developer material ships.
