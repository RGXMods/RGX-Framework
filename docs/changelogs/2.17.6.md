# RGX-Framework v2.17.6

Package: `RGX-Framework-v2.17.6.zip`, 106 runtime files, plus `release.json`.

- The framework settings page no longer shows the global Theme card (main colour, interface style, corners) by default. Those controls change the framework's shared theme, which only the addons that build under it follow, so for every other RGX addon they did nothing. The card now appears only when BLU or Simple Quest Plates (any flavor) is loaded.
- Release cards on Discord use one format across the RGX addons.
