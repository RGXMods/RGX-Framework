# RGX-Framework v2.7.19 - 2026-10-17

- The login-time SharedMedia scan no longer treats the framework's own
  `RGXSharedMedia` registry as a generic addon global and no longer re-bridges
  sound paths a live registry entry still claims; direct-path dedup state is
  preserved across scans. The redundant work flagged by the
  `[RGX:timer-slow] SharedMedia:QueueScan` budget warning is removed.
- World-map pin and waypoint primitives (`RGXWorldMap`) join the game modules:
  pin lifecycle on the world map and minimap, with zone data isolated behind
  one `C_Map` adapter and a HereBeDragons-2.0 fallback for Classic-era
  clients.
- Picker Escape no longer collides with a module alias shortcut.
- Lua 5.1 regressions cover the changes; current public APIs and client
  Interfaces are unchanged. No SavedVariables deletion is required.

Update RGX-Framework, then fully restart WoW.
Package: `RGX-Framework-v2.7.19.zip`, 112 runtime files, plus `release.json`.
