# RGX-Framework v2.20.0

Package: `RGX-Framework-v2.20.0.zip`, 111 runtime files, plus `release.json`.

- Added `RGX:GetInventory()` for live counts, shared-reagent material plans and inventory-change subscriptions. No new global alias, declarative grammar or parallel callback registry.
- Inaccessible or unavailable counts remain unknown rather than a fabricated zero or shortage. Modern reagent-bank flags occupy the correct native position; existing two-argument calls retain their behavior.
- Corrected modern item-info tuple handling while preserving existing compatibility forms.
- Shared event, timer and declarative diagnostics contain hostile error formatting and failing error-handler acquisition. Registry-only module initialization diagnostics cannot abort framework readiness.
