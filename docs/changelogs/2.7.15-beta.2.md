# RGX-Framework v2.7.15-beta.2

Opt-in beta; stable remains v2.7.14.

- Declarative one-line options controls ship: strings such as
  `"toggle enabled 'Enable'"` or `"slider volume 0-100 'Volume'"` compile
  to the shipped table control forms at render time (`slider volume 0-100`,
  `dropdown quality low|high`, `color accent`, `font titleFont`,
  `button 'Text' Method`, `header 'Text'`, `label 'Text'`).
- Schema marks the one-line control grammar as shipped; the validator no
  longer reports string controls as tier4.

Package: `RGX-Framework-v2.7.15-beta.2.zip`, 109 runtime files, plus
`release.json`. Card-grid columns remain the Tier 4 frozen form.
