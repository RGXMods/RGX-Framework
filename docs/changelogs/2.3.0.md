# v2.3.0 — 2026-07-03

## New

- **RGXTooltip** — `Tip:Show(anchorFrame, opts)` / `Tip:Attach(frame, builder)` collapse the `SetOwner → ClearLines → AddLine × N → Show` composition boilerplate found across 71 GameTooltip call sites surveyed in BattlePetUtility. `Tip:HookNative(typeName, callback)` safely wraps Blizzard's `TooltipDataProcessor` for augmenting native item/spell/unit/aura/pet/mount/macro tooltips using human vocabulary, never `Enum.TooltipDataType`. Blizzard's own dispatch is not pcall-wrapped, so `HookNative` pcall-guards every callback — one addon's tooltip hook can no longer break tooltip rendering addon-suite-wide.
- **`tools/rgx-visual-test/`** — in-tree dev/debug addon for manually QA-testing RGX's UI controls (color picker, toggles, sliders, nested dropdowns, font/texture dropdowns) in-game. `/rgxvisual` opens the full tabbed panel, `/rgxcolor` opens the color picker directly. Not player-facing; excluded from the packaged zip.

## Fixed

- **`RGXColorPicker` never actually rendered.** Six frames inside `GetFrame()`'s construction chain called `:SetBackdrop()` without the `BackdropTemplate` template mixin — a hard error in modern WoW. The very first sub-builder hit this immediately, so the frame was never cached and `Show()` silently died every time, for every caller, since the module was introduced. All 6 sites fixed.
- **Hue bar had no rainbow.** With the picker actually rendering for the first time, this stub was exposed: the hue bar was a static flat red — the original code's own comment admitted the gradient was never implemented. Replaced with a real 6-segment gradient covering the full 0–360° hue range.
- **Saturation/value box had no saturation axis.** Only the value (brightness) gradient worked; the box showed a flat hue color fading to black vertically with no white-to-color transition, so dragging toward the desaturated edge looked identical to the saturated edge. Replaced with a reactive `SetGradient` that recolors as the selected hue changes.

## Upgrade Notes

No breaking changes. If you use `RGX:GetColorPicker():Show(...)` or `UI:CreateColorPicker(...)`, it now actually works.
