# RGX-Framework 2.7.7

Released 2026-09-21.

- Fixed the `tonumber` crash in `compat.lua` on the WoW Forever beta:
  `GetBuildInfo()` returns six values on modern clients, and
  `select(4, ...)` leaked extra values into `tonumber`'s base parameter.
  Now captures the 4th return into a named local.
- New `core/compat_api.lua` module: `RGX.API.*` provides guarded access
  to WoW API functions that may not exist on all client flavors. Covers
  items, containers, money, party/raid, raid targeting, resurrection,
  transport, and maps — with modern?legacy?stub fallback chains.
- Minimap button positions now prefer the durable
  `RGXFrameworkDB.RGXMinimapPositions` store over addon-level storage,
  so positions survive SavedVariables loss even when config defaults
  re-apply the default angle.
- Minimap `GetAngle` and `SetAngle` mirror drag angles into the durable
  framework database, keyed by button name, for all RGX addons.
- Published asset name: `RGX-Framework-v2.7.7.zip`; the addon archive
  contains 101 runtime files.
