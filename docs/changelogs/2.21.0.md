# RGX-Framework v2.21.0

Package: `RGX-Framework-v2.21.0.zip`, 111 runtime files, plus `release.json`.

- Added the generated master capability registry with 106 capabilities, 48 traditional-library mappings, native-domain evidence, ownership reviews and a dependency-aware backlog. The registry ships in the contract bundle and as `rgx://schemas/capability-registry`.
- Added opt-in latest-per-key event bucketing to `RGX:RegisterEvent` and `RGX:RegisterUnitEvent`: final `{ bucket, key }` options preserve ordinary dispatch while coalescing current-state bursts through the existing timer owner.
- Deterministic first-seen key ordering, FIFO detached overflow batches, a 128-key bound, key-failure/NaN fallback and safe unregister/replacement/cancellation handling. Nil arguments and arity are preserved.
- Added regression and rejection fixtures, sanitized-public-tree validation and a 10,000-event burst benchmark. Transition streams and the declarative `on` grammar are unchanged; consumer migration is optional.
