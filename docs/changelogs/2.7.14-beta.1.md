# RGX-Framework v2.7.14-beta.1

Opt-in UI beta; stable remains v2.7.13.

- `UI:CreateButton` selection state: `btn:SetSelected(bool)` keeps the hover
  highlight after the pointer leaves (same contract as active option tabs),
  honored across design and fallback button skins and composed hover hooks.
- Minimap buttons keep `frame.backdrop` free for ElvUI-style collector frames;
  the framework's own background texture moves to `frame.backgroundTexture`,
  and a collector that reparents the button owns its layout until release.
- `RGX:NewDatabase` gains opt-in `legacyFlat` migration: an existing flat
  settings table moves into the Default profile with values deep-copied, so
  profile adoption cannot discard or alias earlier saved data.

Package: `RGX-Framework-v2.7.14-beta.1.zip`, 109 runtime files, plus
`release.json`. Local preview/nameplate testing continues in the beta channel.
