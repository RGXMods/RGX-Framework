# v2.2.1 — 2026-07-02

## Fixed

- Packaging hotfix: the v2.2.0 zip leaked `docs/`, `schemas/`, and `tools/` into the player download. Root cause: the BigWigs packager's ignore matcher silently fails on directory entries written with trailing slashes (`docs/` vs `docs`) — plain-file entries were unaffected. All directory entries normalized; the zip now contains only the runtime: TOC, XML, `core/`, `modules/`, `media/`, `LICENSE.txt`.

No code changes; identical runtime to v2.2.0.
