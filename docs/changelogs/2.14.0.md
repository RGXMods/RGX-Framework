# RGX-Framework v2.14.0

Package: `RGX-Framework-v2.14.0.zip`, 106 runtime files, plus `release.json`.

- Added `RGXLoot:OnItemLooted(fn)`: fires once per bag update for the first newly acquired item of any quality. `fn(bag, slot, quality)`.
- Fixed `RGXLoot:OnRareLoot` repeating for an item that stays flagged new. Each slot is now reported once, and re-armed when it stops being new.
- Added `RGXHonor:OnHonorGain(fn)`: fires for every honor award (honorable kills, objectives, bonuses). `fn(amount, message)`; `amount` is nil when the message cannot be read.
- The dropdown inline Play button now uses the design-system colours, with more edge padding so it stays inside the menu frame.
- Release tooling now publishes the exact CurseForge and Wago game version for each flavor (retail 12.1.5, Forever 1.60.1) instead of the newest or a wrong one.
