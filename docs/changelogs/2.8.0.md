# RGX-Framework v2.8.0 - 2026-10-17

- New library module `RGXTimers` (`RGX:GetTimers()`, global `RGXTimers`):
  frame-based countdown/progress bars that replace LibCandyBar-3.0 for consumer
  addons. Bars keep native frame methods (`SetPoint`, `SetScript`, `Show`,
  `Hide`, `IsShown`, `SetScale`, ...), carry `exp`/`start` stamps for pooled
  sorting, and support labels, icons, colors, textures, height, countdown/fill
  modes, and completion/cancel callbacks.
- `libraries/timers/timers.lua` loads on all six flavors. `docs/TIMERS.md`
  documents the API with a LibCandyBar mapping table, and the API catalog gains
  the `timers` entry with the `RGX:GetTimers()` shortcut.
- `tools/ci/timers-runtime-check.mjs` adds 11 Lua 5.1 scenarios (registration,
  frame inheritance, completion vs cancel callbacks, progress mode, value
  clamping, `CancelAll`, updater labels) and runs in `lua-runtime-check`.
- Current public APIs and client Interfaces are unchanged. No SavedVariables
  deletion is required.

Update RGX-Framework, then fully restart WoW.
Package: `RGX-Framework-v2.8.0.zip`, 113 runtime files, plus `release.json`.
