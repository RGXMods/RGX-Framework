## v2.4.0 - 2026-07-03

**RGXColorPicker visual redesign.** Replaced the flat-square control set with a circular vocabulary consistent across the whole picker:

- SV box and hue bar now use a ring-and-fill drag handle (a white ring with a live-colored center) instead of a borrowed Blizzard minimize-button icon.
- Preset swatches and the current-color preview are circular, using the same `SetMask`-based technique already proven in `modules/minimap/minimap.lua`.
- Preset swatches get hover feedback (a themed highlight ring).
- Hex/RGB inputs highlight their border in the active theme's primary color on focus.
- Panel chrome (background, borders, buttons) now goes through `RGXDesign` tokens instead of hardcoded grays, and the close/OK/Cancel buttons use `Design:CreateButton` for consistency with the rest of the framework's UI.
- Palettes with no colors (e.g. an empty "Recent" row) no longer reserve empty vertical space in the layout.

**Text-wrap bug fixed.** `UI:CreateLabel` created FontStrings with no width constraint, so long descriptive text silently rendered past the edge of its parent frame instead of wrapping. `CreateLabel` now accepts an opt-in `options.width` (enables `SetWordWrap` + justification); short single-line labels are unaffected.

**Packaging changes:**

- `tools/rgx-visual-test/` has moved out of this repo entirely — it's now merged into the `RGX-Hello` repo, which serves as both the minimal reference addon and the visual QA harness.
- Historical v2.4.0 behavior: `tools/rgx-mcp/` was added to the packaged addon ZIP. This was reversed by v2.6.1; it is now a temporary source-only CI fixture and never ships to players.
