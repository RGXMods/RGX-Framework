# v2.7.10

Stable maintenance release shipping the accumulated main-branch fixes since
v2.7.9. No API breaks; every consumer-facing change is additive.

## Stability (live bug fixes)

- **Database self-heal for corrupted profile stores.** A metatable-poisoned
  SavedVariables table (for example a proxy table accidentally written into
  the profile store by any addon) previously looped every database access
  into a `C stack overflow` at `database.lua:340`, killing each consumer's
  event handlers and framework timers. `ActiveProfile` now validates that
  the profile store and the active profile are plain tables; on corruption
  it logs one `RGX:Error` and rebuilds the entry plain with defaults, so one
  bad write can no longer hard-crash every read. Regression coverage poisons
  both entries with the exact live loop and proves healed reads.
- **Card `AutoHeight` method-call fix.** `card:AutoHeight()` passed the card
  as numeric padding and crashed layout construction with an
  arithmetic-on-table error (observed as an options page failing to load).
  Both the method-call form and the legacy dot-call form are now supported;
  a real `CreateCard`/flow regression proves padding, non-overlap, and
  reflow.

## New framework capabilities

- **Close button factory** — `UI:CreateCloseButton(parent, opts)`:
  framework-owned window chrome (native `UIPanelCloseButton` art, size,
  anchor, tooltip, custom click action). `CreateOptionsPanel` now consumes
  it; pass `opts.closeButton = false` to skip it.
- **Config gear + dialog primitives** — `UI:CreateConfigButton(anchor, opts)`
  and `UI:CreateConfigDialog(parent, opts)`: the sub-menu configuration
  affordance as shipped framework chrome so consumers stop hand-rolling
  advanced-settings windows.
- **Suite brand icons** — `media/round.tga` (minimap buttons) and
  `media/square.tga` (header/panel icons), 256x256 32-bit, packaged as
  runtime media; the minimap module documents the convention.
- **Wago connection** — suite project ID `E6gz1DN1` registered in every
  flavor TOC.

## Architecture (developer-facing, no runtime behavior change)

- Contract promoted to a first-class layer: `contract/schemas` (authoritative
  JSON schemas) and `contract/engine` (transport-independent validation,
  generation, audit, and definition-authoring engines shared by MCP, CI, and
  future tooling).
- MCP server thinned to a transport adapter over the shared engines.
- Module taxonomy machine-enforced: all 27 modules declare
  `category`/`depends`/`flavors`/`stability` at registration; CI proves the
  dependency graph acyclic, XML load order satisfies dependencies, and
  flavor gates agree with `core/compat.lua`.
- **Frozen public global surface**: the 31 framework globals are now a fixed
  contract; CI fails on any new `_G` write and on dead allowlist entries.
- **Runtime boundary enforcement**: no `core/` or `modules/` Lua may
  reference `tools/`, `contract/`, `.reference/`, `rgx-mcp`, `node_modules`,
  or use `require`/`dofile`/`loadfile` — the player runtime is provably
  self-contained.
- `docs/ARCHITECTURE.md` documents the eight-layer boundary map, dependency
  direction, and ships-vs-source-only inventory.
- Locale coverage extended with a `ptPT` baseline module.

## Compatibility

- One framework, one instance, one dependency: `RequiredDeps: RGX-Framework`.
- Retail `120100` + WoW Forever beta `16001` in the base TOC; Classic Era
  `11509`, TBC `20506`, Wrath/Titan `38002`, Cataclysm `40402`, Mists
  `50504` in their flavor TOCs. All six ship together.
- Player archive: `RGX-Framework-v2.7.10.zip` — 108 runtime files (TOCs,
  XML, core, modules, media, license). No tooling, docs, schemas, or
  developer material ships.
