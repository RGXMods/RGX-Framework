# RGX-Framework v2.16.0

Package: `RGX-Framework-v2.16.0.zip`, 106 runtime files, plus `release.json`.

- Minimap buttons gain `btn:SetCompartmentVisible(show)` and `btn:IsCompartmentVisible()`, so an addon can offer its Blizzard Addons-menu entry as a setting and apply it without a reload. On a client that cannot remove an entry, `SetCompartmentVisible(false)` returns `false` and the choice applies after the next reload.
- New [Releasing an RGX addon](../ADDON-RELEASE.md) guide and `docs/release-templates/` (GitHub release workflow, `.pkgmeta`, GitLab CI include). It documents the flow every addon uses: GitLab validates and mirrors, GitHub builds the release and Discord card, CurseForge packages the tag itself.
