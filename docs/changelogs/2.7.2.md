# RGX-Framework 2.7.2

Released 2026-08-22.

## Event Lifecycle Hotfix

- Fixed the pending frame-event queue so handlers registered while RGX is
  dispatching another WoW event are promoted to real frame registrations when
  the outermost dispatch returns to a safe state.
- This closes the failure mode where consumer addons could have callbacks
  present in `RGX.events` while WoW never delivered `QUEST_ACCEPTED`,
  `QUEST_TURNED_IN`, level-up, achievement, or other feature events.
- Registrations created from RGX timer callbacks now receive the same deferred
  flush guarantee when the timer driver exits.
- `UnregisterUnitEvent` and `UnregisterAllUnitEvents` now clean up pending and
  native frame state symmetrically while preserving shared event registrations
  that still have regular handlers.
- Combat-deferred registrations remain queued until frame registration is safe.

## Verification

- Added 35 Lua 5.1 event-lifecycle checks for login bootstrap, nested event
  dispatch, unit-event registration, timer-created registration, combat
  deferral, removal-before-flush, and shared regular/unit handler cleanup.
- Existing declarative-timer runtime coverage remains at 166 checks.
- Existing restricted-aura runtime coverage remains at 86 checks.
- Lua syntax, schema, six-flavor compatibility, and deterministic package
  boundary checks remain green.
