# RGX-Framework 2.5.1

## Compatibility Foundation

- Added centralized Retail/Classic capability adapters for addon metadata,
  auras, quest-log access, reputation, and shared UI paths.
- Hardened `UNIT_AURA` update payload container access for restricted values.
- Added pet-battle query APIs used by consumer migration work.

## UI And Controls

- Added context-menu and options-tab extension APIs.
- Improved font-family replacement and redraw handling.
- Shipped accumulated embedded color-picker layout, cursor, preview, and input
  fixes.

This release established the compatibility foundation completed by the six-TOC
v2.6.0 release.
