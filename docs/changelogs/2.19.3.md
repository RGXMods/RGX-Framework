# RGX-Framework v2.19.3

Package: `RGX-Framework-v2.19.3.zip`, 110 runtime files, plus `release.json`.

- `/rgxf debug` enables framework diagnostics, including slow-options timing reports, instead of switching only font debugging. Running it again disables both. Timing thresholds are unchanged.
- Source tooling no longer tracks an absolute workstation dependency link; dependencies remain local and install from the existing lockfile.
