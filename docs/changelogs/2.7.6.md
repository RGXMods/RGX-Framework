# RGX-Framework 2.7.6

Released 2026-09-20.

- Minimap button positions are now durable across the entire RGX addon suite:
  every RGXMinimap button mirrors its drag angle into
  `RGXFrameworkDB.RGXMinimapPositions` keyed by button name, and GetAngle
  restores from that store (writing the value back into the addon's own
  SavedVariables) when the addon's angle is missing. Addon SavedVariables can
  be lost on beta clients during crashes or storage wipes; the framework
  database survives, so minimap icons no longer snap back to the default
  position.
- Published asset name: `RGX-Framework-v2.7.6.zip`; the addon archive contains
  100 runtime files.
