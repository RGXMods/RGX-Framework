## v2.5.0 - 2026-07-04

**Progressive-disclosure audit of the DSL.** Governing principle, now encoded in `CLAUDE.md`: every DSL key works bare with assumed arguments AND accepts an advanced form — simple addons stay simple, advanced addons are possible, and the DSL never grows a second API. Auditing every shipped key against that principle found two real bugs and three missing forms:

**Fixed:**

- **Declarative `minimap` buttons forgot their dragged position.** `RGX.Addon` called the minimap module's `Create` without `storage`, so the angle was never saved — every DSL addon's button snapped back to default on reload. Creation now happens inside ADDON_LOADED after `addon.db` exists, and persists the angle there by default. The bare form also now assumes a left-click that opens the addon's options panel.
- **Declarative `dropdown` controls saved but never restored.** The mapper never passed `value = addon.db[key]`, so a dropdown reopened blank after reload despite the setting being saved — the exact save-without-restore bug class this framework's pitch says it kills.

**New forms (additive, nothing existing changes):**

- `minimap = { icon = ..., tooltip = ..., defaultAngle = ..., onRightClick = ... }` — full passthrough to the minimap module.
- `{ color = "dbKey", label?, default? }` control — the DSL now reaches `UI:CreateColorPicker`; the default color is assumed from the db defaults for that key.
- `slash = { "cmd", "alias", handler = function(addon, msg) ... end }` — override the assumed open-the-panel handler.

**Changed:**

- Auto-derived SavedVariables names strip non-identifier characters (`"RGX-Hello"` → `RGXHelloDB`), aligning the runtime with what `rgx_generate_addon` already emitted. Hyphenated-name addons that relied on the old raw `name.."DB"` concatenation should set `dbName` explicitly.

**Documented:**

- The options **layout model** as proven in BLU — panel → main page + tabs → tabs can be multi-paged → 1–2 column card grid → rows/cards holding the widgets — recorded in the schema, `docs/DECLARATIVE-API.md`, and `docs/ACE3-ANALYSIS.md` as the Tier 4 implementation target (`columns = 1|2|3` frozen; 1–2 is the proven range).
- `docs/ACE3-ANALYSIS.md` gained a **verified parity map**: where RGX adds value (declarative front door, schema/MCP conformance tooling, centralized safety infrastructure, RGXDesign, and RGX-Hello), where it is at parity (events, timers, hooks, profiles-capable DB, shared media), and what is intentionally absent until a real addon needs it (comm/serializer, locale).

Schema updated for all new forms (`colorControl`, minimap object form, slash handler form); `tools/rgx-mcp/test/test-rgx-hello.mjs` re-run green.
