# RGX-Framework v2.19.2

Package: `RGX-Framework-v2.19.2.zip`, 110 runtime files, plus `release.json`.

- The consumer packager keeps the existing `sounds/user/README.txt` marker, so extracting a package creates its custom-sounds folder. Unrelated text files and development documentation stay excluded. Consumer release workflows must use this packager version to pick up the fix.
- Declarative event handlers support `{ handler = fn, unit = "player" | { ... }, throttle = seconds }`. Unit filtering and throttling use the existing framework event lifecycle; bare handler forms stay unchanged.
