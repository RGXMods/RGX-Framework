# RGX-Framework v2.17.0

Package: `RGX-Framework-v2.17.0.zip`, 106 runtime files, plus `release.json`.

- New `UI:CreateStandardCard(parent, opts)`: a card with the options every RGX mod shares, stored under the same keys everywhere: `minimapIconEnabled`, `addonMenu`, `chatOutput`, `loginMessage` and `chatPrefix`. Rows fill the card, so long labels never run into the ON/OFF text.
- New `RGX:CreateChat(opts)`: `Print` and `Login` honour those keys, use the addon's branded title as the default prefix, show a typed prefix as written, and respect the framework-wide login-message switch.
- See [UI-CONTROLS](../UI-CONTROLS.md) and [API](../API.md).
