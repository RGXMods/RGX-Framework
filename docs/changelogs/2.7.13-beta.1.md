# RGX-Framework v2.7.13-beta.1

Opt-in beta for SQP and BLU feedback. Stable remains v2.7.12.

- Click checkbox text as well as the checkbox; hover callbacks preserve skins.
- Slider value-display modes: always, hover-only, or hidden; contract and
  generation support agree with runtime.
- Shared profile editor, protected/duplicate-name handling and DB-backed CRUD.
- Shared reset baselines, flexible row allocation, one/two-column cards and
  width/show auto-height reflow.
- Design-backed dialogs with optional resize grips and capability-based bounds.
- Main-color aliases and reusable surface/hover/border shades.
- Modern context menus no longer depend on a selection-dropdown template;
  programmatic selection restoration is silent and refreshes visible text.
- Valid UTF-8 Lua strings pass the source audit without weakening unsafe aura
  detection or invalid-Lua rejection.
- Beta packaging preserves stable public release markers and provider IDs.

Package: `RGX-Framework-v2.7.13-beta.1.zip`, 109 runtime files, plus `release.json`.
New UI requires client feedback for geometry, rendering, reload and combat
behavior; headless checks do not establish complete live-client validation.
