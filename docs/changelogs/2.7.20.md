# RGX-Framework v2.7.20 - 2026-10-17

- Minimap buttons registered through `RGX.Addon(name, { minimap = true })` now
  persist their angle and visibility when the consumer addon does not declare
  its own database. Storage falls back to the framework SavedVariables; addons
  with `opts.db` keep their existing database behavior unchanged.
- Lua 5.1 regression coverage in `profile-persistence-check.mjs` covers the
  fallback path, including angle, visibility, and re-creation restore.
- Current public APIs and client Interfaces are unchanged. No SavedVariables
  deletion is required.

Update RGX-Framework, then fully restart WoW.
Package: `RGX-Framework-v2.7.20.zip`, 112 runtime files, plus `release.json`.
