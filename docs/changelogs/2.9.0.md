# RGX-Framework v2.9.0 - 2026-10-19

- New declarative layout model: options tabs can contain page nodes that create
  multi-page tabs. Each page uses `grid = 1|2` to distribute cards across a
  card grid, and each card uses `columns = 1|2` for its internal control
  flows. Cards and controls fill in declaration order and reuse the same
  db-bound factories as plain tabs, so reopening a panel restores values and
  displayed control state.
- The MCP generator accepts declarative `pages` and emits contract-congruent
  page/card layouts; generated output is deterministic and parses as Lua 5.1.
- Layout declarations are validated before addon registration. Invalid grids,
  columns, empty cards/controls, nested layouts, mixed page/control tabs, and
  malformed control strings fail without registering the addon or creating a
  panel.
- Existing `options.columns` control-list behavior is unchanged and cannot be
  combined with page layouts.
- Current public APIs and client Interfaces are unchanged. No SavedVariables
  deletion is required.

Update RGX-Framework, then fully restart WoW.
Package: `RGX-Framework-v2.9.0.zip`, 114 runtime files, plus `release.json`.
